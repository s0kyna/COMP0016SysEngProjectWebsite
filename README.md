# O2C PROJECT REPORT WEBSITE

This version contains the full report structure

1 - Home / Introduction  
2 - Requirements + Use Cases  
3 - Research + Design Choices  
4 - UI Design  
5 - Proposed Design + Implementation  
6 - Testing Strategy  
7 - Evaluation  
8 - Appendices  

## HOW TO OPEN

1. Extract the ZIP.
2. Open the extracted folder.
3. Double-click `index.html`.
4. The site will open directly in your browser.

## HOW TO USE

- Use the sidebar to move between report sections.
- On smaller screens, use the **Sections** button to open the navigation menu.
- No installation or web server is required.

## EDITING

- Open the extracted folder in VS Code.
- Edit `index.html` for content.
- Edit `styles.css` for appearance.
- Edit `script.js` only if you want to change the sidebar behaviour.

If the page does not open correctly, make sure `index.html`, `styles.css`, `script.js`, and the `images` folder are all kept together in the same project folder.
